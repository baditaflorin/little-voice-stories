# 0070 - Documentation Reality Alignment Process

- Status: accepted

## Context

README and postmortem language can drift ahead of actual product completeness.

## Decision

Only document user-facing capabilities that have a working UI path and a test or manual verification note. Add an explicit limitations section for still-out-of-scope pathways.

## Consequences

- README updates are part of Phase 3 scope, not afterthoughts.

## Alternatives Considered

- Keep aspirational copy: rejected because it confuses strangers.
