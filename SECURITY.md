# Security Policy

## Supported Versions

Security fixes target the latest tagged release.

## Reporting A Vulnerability

Please report suspected vulnerabilities privately by email to baditaflorin@users.noreply.github.com.

Do not include child drawings, parent voice recordings, or other personal data in public issues.

## Privacy Baseline

Little Voice Stories is designed as a static, local-first app. In the v1 happy path, kid drawings, parent voice recordings, story drafts, and generated narration data stay in the browser.
